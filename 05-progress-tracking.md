# Progress Tracking & Thresholds, by Escalate / thrFPS

## Standard Logging Format

Always log your sessions utilizing this standardized syntax:

```
(task name) - (sensitivity and FOV)
(PR) [threshold] (date)
```

### Real-World Example

```
VT Threeshot ADVANCED - 64cm 103
1000 [970] (18/10) 1050 [970] (19/10) 1060 [990] (22/10)
```

On 10/18 the PR was 1000 with a Threshold of 970. On 10/19 the PR increased to 1050, yet the Threshold remained at 970: consistency had not yet solidified sufficiently to warrant an increase. Only on 10/22 did the Threshold advance to 990, alongside a new PR of 1060.

A Threshold changes exclusively when genuine mechanical consistency progresses, never due to an isolated fortunate run.
